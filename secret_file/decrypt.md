
## Decrypt

```bash
openssl aes-256-cbc -d -a -pbkdf2 -in test.enc -out test.jpg

```

มาดูกันทีละตัวอักษรและพารามิเตอร์ว่า เมื่อสั่งถอดรหัสแล้ว เบื้องหลังมันทำงานย้อนกลับอย่างไรครับ:

---

### 1. `openssl`

* **หน้าที่:** เรียกใช้งานโปรแกรม OpenSSL ตัวเดิม เพื่อเป็นหัวเรือใหญ่ในการประมวลผลคำสั่งนี้

### 2. `aes-256-cbc`

* **หน้าที่:** บอกกฎและกติกาว่า **ตอนเข้ารหัสใช้สูตรไหน ตอนถอดรหัสก็ต้องใช้สูตรเดิมเป๊ะๆ**
* **ความหมาย:**
* ต้องใช้ **AES** (มาตรฐานการเข้ารหัสขั้นสูง)
* ขนาดกุญแจต้องเป็น **256 บิต**
* โหมดการทำงานต้องเป็น **CBC** (Cipher Block Chaining)
* *หมายเหตุ:* ถ้าตอนเข้ารหัสใช้ AES-256 แต่ตอนถอดรหัสเผลอพิมพ์เป็น AES-128 ระบบจะถอดรหัสไม่ออกและฟ้องข้อผิดพลาดทันที เพราะรหัสไม่ตรงกัน



### 3. `-d` (Decrypt)

* **หน้าที่:** คำสั่งสลับโหมดจาก "เข้ารหัส" เป็น **"ถอดรหัส"**
* **ความหมาย:** บอก OpenSSL ว่า *“เฮ้! ไฟล์ที่กำลังจะส่งเข้ามามันถูกล็อกกุญแจไว้นะ ช่วยปลดล็อกแล้วคืนร่างเป็นไฟล์เดิมให้หน่อย”* (ถ้าไม่ใส่ `-d` ระบบจะเข้าใจว่าอยากเอาไฟล์ที่เข้ารหัสแล้ว ไปเข้ารหัสซ้ำอีกรอบ)

### 4. `-a` (Base64 Decoding)

* **หน้าที่:** สั่งแปลงข้อมูลหน้าตาประหลาดที่เป็นตัวอักษร Base64 ให้กลับมาเป็น **ไบต์ดิบๆ (Binary)**
* **ความหมาย:** เนื่องจากตอนเข้ารหัสเราใส่ `-a` เพื่อแปลงไฟล์ผลลัพธ์ให้กลายเป็นข้อความตัวอักษร (ที่ก๊อปปี้ไปวางในแชทหรือไฟล์ Text ได้ง่าย) ดังนั้น พอจะถอดรหัส เราจึงต้องบอกให้มันแปลงร่างกลับจากตัวอักษรให้อยู่ในรูปข้อมูลเดิมเสียก่อน เพื่อให้ขั้นตอนถอดรหัส AES ทำงานต่อได้

### 5. `-pbkdf2`

* **หน้าที่:** บอกวิธีแปลง "รหัสผ่าน" ที่คุณพิมพ์เข้าไป ให้กลับมาเป็น "กุญแจ 256 บิต" ชุดเดิม
* **ความหมาย:** เนื่องจากตอนเข้ารหัสเราใช้มาตรฐาน **PBKDF2** ในการผูกรหัสผ่าน เวลาถอดรหัสเราจึงต้องใช้ PBKDF2 ตัวเดียวกันในการคำนวณย้อนกลับ เพื่อสร้างกุญแจดอกเดิมขึ้นมาไขตู้เซฟ (ถ้าตอนเข้ารหัสใช้ PBKDF2 แต่ตอนถอดรหัสลืมใส่ตัวนี้ OpenSSL จะพยายามใช้ระบบเก่าแบบเดิม ซึ่งจะเตือนว่าเป็น Warning หรือถอดรหัสไม่ออกเลยใน OpenSSL เวอร์ชันใหม่ๆ)

### 6. `-in test.enc` (Input File)

* **หน้าที่:** ระบุไฟล์ต้นทางที่จะนำมาถอดรหัส
* **ความหมาย:** ในที่นี้คือไฟล์ล็อกกุญแจ `test.enc` ที่เราเก็บไว้

### 7. `-out test.jpg` (Output File)

* **หน้าที่:** ระบุไฟล์ปลายทางที่ได้จากการถอดรหัสสำเร็จ
* **ความหมาย:** สั่งให้ระบบปลดล็อกข้อมูลแล้วเซฟเก็บไว้เป็นรูปภาพชื่อ `test.jpg` (ซึ่งพอกลับมาเปิดดูก็จะได้รูปภาพเดิมก่อนเข้ารหัสเป๊ะๆ)

---

### ลำดับขั้นตอนการทำงานจริงเมื่อคุณกด Enter:

1. คุณพิมพ์คำสั่ง แล้วระบบจะเด้งถามรหัสผ่าน (`enter AES-256-CBC decryption password:`)
2. คุณพิมพ์รหัสผ่านลงไป (ตัวอักษรจะไม่แสดงขึ้นมาเพื่อความปลอดภัย)
3. OpenSSL จะไปอ่านไฟล์ `test.enc` แล้วแอบดึงค่า **Salt** ที่ถูกฝังไว้ข้างในไฟล์ออกมาผสมกับรหัสผ่านที่คุณพิมพ์
4. ใช้ฟังก์ชัน **PBKDF2** วนคำนวณเพื่อแปลงรหัสผ่าน+Salt ให้กลายเป็น **กุญแจ 256 บิต** ดอกเดิม
5. ใช้โหมด **CBC** พร้อมกุญแจ 256 บิตนั้น ไขรหัสข้อมูลในไฟล์ `test.enc` ย้อนกลับทีละบล็อก
6. แปลงร่างข้อมูลกลับจาก Base64 (`-a`) ให้กลายเป็นไฟล์ภาพปกติ แล้วบันทึกออกเป็น `test.jpg` เป็นอันเสร็จสิ้นครับ!
