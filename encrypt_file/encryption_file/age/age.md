# Encrypt & Decrypt : Use `age`

## option ของคำสั่ง `age` ทั้งหมด

## 1. `-p` = ใช้ password

ย่อมาจาก **password** บอก age ว่า "ให้เข้ารหัสด้วยรหัสผ่านที่ฉันจะพิมพ์"

```bash
age -p -o test.enc test.mp4
```

พอใส่ `-p` age จะถามให้คุณตั้งรหัสผ่าน 2 ครั้ง (พิมพ์ + ยืนยัน)

ถ้าไม่ใส่ `-p` age จะรอรับ **public key** จาก stdin แทน (วิธีเข้ารหัสแบบกุญแจสาธารณะ)

---

## 2. `-o` = ไฟล์ output (ปลายทาง)

ย่อมาจาก **output** บอกว่าจะให้เขียนผลลัพธ์ไปไฟล์ไหน

```bash
age -p -o test.enc test.mp4
#        ↑
#   ผลลัพธ์ไปที่ test.enc
```

เปรียบเทียบกับ OpenSSL จะคล้าย `-out`:

| | age | OpenSSL |
|---|---|---|
| ไฟล์ออก | `-o` | `-out` |
| ไฟล์เข้า | (argument ตัวสุดท้าย) | `-in` |

**ถ้าไม่ใส่ `-o`** age จะเขียนผลลัพธ์ออก **หน้าจอ (stdout)** แทน ซึ่งถ้าเป็นไฟล์ binary จะเพี้ยน ควรใส่ `-o` เสมอ

---

## 3. `-d` = decrypt (ถอดรหัส)

ย่อมาจาก **decrypt** ใช้ตอนถอดรหัส บอก age ว่า "ไฟล์ input นี้ถูกเข้ารหัสอยู่ ให้ถอดออก"

```bash
age -d -o test.mp4 test.enc
#   ↑
#  ถอดรหัส
```

ถ้าไม่ใส่ `-d` age จะถือว่า **กำลังเข้ารหัส** (encrypt) เป็นค่า default

| โหมด | ใส่ flag |
|---|---|
| เข้ารหัส (default) | ไม่ต้องใส่ |
| ถอดรหัส | ใส่ `-d` |

---

## 4. เทียบให้เห็นภาพ

```bash
# ===== เข้ารหัส =====
age -p -o test.enc test.mp4
#   │  │             │
#   │  │             └─ ไฟล์ต้นทาง (input)
#   │  └─ เขียนผลลัพธ์ไป test.enc
#   └─ ใช้รหัสผ่าน

# ===== ถอดรหัส =====
age -d -o test.mp4 test.enc
#   │  │             │
#   │  │             └─ ไฟล์ที่เข้ารหัสไว้ (input)
#   │  └─ เขียนผลลัพธ์ไป test.mp4
#   └─ โหมดถอดรหัส decrypt
```

---

## 5. สรุปตาราง

| option | ย่อจาก | ใช้ทำอะไร | ใช้ตอน |
|---|---|---|---|
| `-p` | password | เข้ารหัสด้วยรหัสผ่าน | เข้ารหัส |
| `-o` | output | กำหนดไฟล์ผลลัพธ์ | ทั้งเข้ารหัส/ถอดรหัส |
| `-d` | decrypt | ถอดรหัส | ถอดรหัส |
| `-a` หรือ `--armor` | armor | ได้ผลลัพธ์เป็น base64 (text) | เข้ารหัส |
| `-r` | recipient | เข้ารหัสด้วย public key | เข้ารหัส |
| `-i` | identity | ใช้ private key ถอดรหัส | ถอดรหัส |

---

## 6. ตัวอย่างครบชุด

```bash
# เข้ารหัสด้วยรหัสผ่าน ได้ผลลัพธ์เป็น base64
age -p -a -o test.enc test.mp4

# ถอดรหัส
age -d -o test.mp4 test.enc
```

จะเห็นว่า age ออกแบบให้สั้น — เข้ารหัสใช้แค่ `-p` + `-o` ถอดรหัสใช้แค่ `-d` + `-o` เท่านั้น ไม่ต้องจำ algorithm เหมือน OpenSSL
