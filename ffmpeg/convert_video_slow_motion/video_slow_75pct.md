# ffmpeg Slow Motion 75%

คู่มือและสคริปต์สำหรับทำให้วิดีโอเล่นช้าลงเหลือ 75% ด้วย ffmpeg (ทั้งภาพและเสียง) รองรับทั้งไฟล์เดี่ยวและแปลงเป็นชุด

## ความต้องการ

- [ffmpeg](https://ffmpeg.org/download.html) ติดตั้งแล้ว และเรียก `ffmpeg` ได้จาก terminal

ตรวจสอบด้วย:

```bash
ffmpeg -version
```

## วิธีใช้งานเร็ว

### วิดีโอที่มีเสียง

```bash
ffmpeg -i input.mp4 -filter_complex "[0:v]setpts=1.3333*PTS[v];[0:a]atempo=0.75[a]" -map "[v]" -map "[a]" output.mp4
```

### วิดีโอที่ไม่มีเสียง (หรือต้องการตัดเสียงทิ้ง)

```bash
ffmpeg -i input.mp4 -vf "setpts=1.3333*PTS" -an output.mp4
```

> ถ้าไฟล์ไม่มีเสียงแต่ใช้คำสั่งแบบแรก ffmpeg จะ error เพราะหา `[0:a]` ไม่เจอ

## แปลงทั้งโฟลเดอร์

ผลลัพธ์จะถูกเก็บในโฟลเดอร์ `out/`

**Linux / macOS (bash)**

```bash
mkdir -p out
for f in *.mp4; do
  ffmpeg -i "$f" -filter_complex "[0:v]setpts=1.3333*PTS[v];[0:a]atempo=0.75[a]" -map "[v]" -map "[a]" "out/$f"
done
```

**Windows (PowerShell)**

```powershell
mkdir out
Get-ChildItem *.mp4 | ForEach-Object {
  ffmpeg -i $_.FullName -filter_complex "[0:v]setpts=1.3333*PTS[v];[0:a]atempo=0.75[a]" -map "[v]" -map "[a]" "out\$($_.Name)"
}
```

## ปรับเป็นเปอร์เซ็นต์อื่น

- `setpts` = 100 ÷ เปอร์เซ็นต์ความเร็ว
- `atempo` = เปอร์เซ็นต์ความเร็ว ÷ 100

| ความเร็ว | setpts | atempo |
|---|---|---|
| 90% | `1.1111*PTS` | `0.9` |
| 75% | `1.3333*PTS` | `0.75` |
| 70% | `1.4286*PTS` | `0.7` |
| 50% | `2.0*PTS` | `0.5` |
| 25% | `4.0*PTS` | `0.5,0.5` (ต่อกัน 2 ตัว) |

`atempo` รองรับช่วง 0.5–100 ต่อหนึ่งฟิลเตอร์ ถ้าต่ำกว่า 50% ให้ต่อหลายตัว เช่น 30% ใช้ `atempo=0.5,atempo=0.6`

## คำสั่งทำงานยังไง

```text
ffmpeg -i input.mp4 -filter_complex "[0:v]setpts=1.3333*PTS[v];[0:a]atempo=0.75[a]" -map "[v]" -map "[a]" output.mp4
```

| ส่วนของคำสั่ง | ความหมาย |
|---|---|
| `-i input.mp4` | ไฟล์ต้นฉบับ (ถ้าชื่อมีเว้นวรรคให้ใส่เครื่องหมายคำพูด) |
| `-filter_complex "..."` | ใช้ฟิลเตอร์หลายสายพร้อมกัน (ภาพและเสียง) คั่นแต่ละสายด้วย `;` |
| `[0:v]` / `[0:a]` | สตรีมภาพ / เสียง จากไฟล์ input ลำดับที่ 0 |
| `setpts=1.3333*PTS` | คูณเวลาของแต่ละเฟรมด้วย 1.3333 (100 ÷ 75) เฟรมห่างขึ้น วิดีโอเลยช้าลง |
| `atempo=0.75` | ทำให้เสียงช้าลงเป็น 0.75 เท่า โดยรักษา pitch ไว้ |
| `[v]` / `[a]` | ชื่อผลลัพธ์ของแต่ละสาย |
| `-map "[v]" -map "[a]"` | เลือกผลลัพธ์ที่ผ่านฟิลเตอร์แล้วไปใส่ในไฟล์ปลายทาง |
| `output.mp4` | ไฟล์ผลลัพธ์ (ต้องชื่อไม่ซ้ำกับ input) |

ตัวเลขของภาพและเสียงต้องสัมพันธ์กัน (1 ÷ 1.3333 ≈ 0.75) ไม่เช่นนั้นภาพกับเสียงจะเลื่อนไม่ตรงกัน

### ลำดับการทำงาน

1. ffmpeg เปิด `input.mp4` แล้วแยกสตรีมภาพกับเสียง
2. สายภาพผ่าน `setpts` เวลาของทุกเฟรมถูกคูณด้วย 1.3333
3. สายเสียงผ่าน `atempo` เสียงถูกยืดเป็น 1 ÷ 0.7 เท่า
4. `-map` เลือกสองสายที่ผ่านฟิลเตอร์แล้ว
5. ffmpeg encode ใหม่ทั้งภาพและเสียง แล้วรวมเป็น `output.mp4`

**ตัวอย่าง:** วิดีโอยาว 60 วินาที เมื่อปรับเป็น 70% จะยาว 60 ÷ 0.7 ≈ 85.7 วินาที

## ข้อควรระวัง

- **ต้อง encode ใหม่** จึงใช้เวลา และคุณภาพอาจลดลงเล็กน้อย ถ้าต้องการคุมคุณภาพ ให้เพิ่ม `-crf 18 -preset slow` ก่อนชื่อไฟล์ output
- **ภาพกระตุกเมื่อช้ามาก ๆ** ใช้ `minterpolate` สร้างเฟรมเพิ่มได้ (ช้ากว่ามาก แต่ภาพนุ่มขึ้น):

  ```bash
  ffmpeg -i input.mp4 -filter_complex "[0:v]setpts=1.3333*PTS,minterpolate=fps=60[v];[0:a]atempo=0.75[a]" -map "[v]" -map "[a]" output.mp4
  ```

- **ชื่อไฟล์วิดีโอที่มีเว้นวรรคหรืออักขระพิเศษ** ต้องใส่เครื่องหมายคำพูดครอบเสมอ

## ภาพรวม ตัวอย่าง 70 %

คำสั่งนี้ทำ 3 อย่าง คือ อ่านไฟล์ `input.mp4` แล้วทำให้ภาพช้าลงเหลือ 70% พร้อมทำให้เสียงช้าลงเหลือ 70% เท่ากัน จากนั้นรวมภาพกับเสียงเข้าด้วยกันแล้วบันทึกเป็น `output.mp4`

## แยกทีละส่วน

### 1. `ffmpeg`
ชื่อโปรแกรมที่เรียกใช้

### 2. `-i input.mp4`
`-i` คือ input หมายถึงไฟล์ต้นฉบับที่จะนำมาแปลง ชื่อไฟล์ต้องตรงกับของจริง ถ้าชื่อไฟล์มีเว้นวรรคให้ใส่เครื่องหมายคำพูด เช่น `-i "my video.mp4"`

### 3. `-filter_complex "..."`
บอก ffmpeg ว่าจะใช้ฟิลเตอร์แบบซับซ้อน คือมีหลายสายพร้อมกัน (สายภาพกับสายเสียง) ข้อความในเครื่องหมายคำพูดคือรายการฟิลเตอร์ทั้งหมด

ข้างในมี 2 สาย คั่นด้วย `;` ครับ

**สายภาพ:** `[0:v]setpts=1.4286*PTS[v]`

| ส่วน | ความหมาย |
|---|---|
| `[0:v]` | เลือกสตรีมภาพ (video) จากไฟล์ input ลำดับที่ 0 (ไฟล์แรก) |
| `setpts=1.4286*PTS` | ฟิลเตอร์ปรับเวลาของแต่ละเฟรม |
| `[v]` | ตั้งชื่อผลลัพธ์ว่า `v` ไว้เรียกใช้ทีหลัง |

**`setpts` ทำงานยังไง**
PTS (Presentation Time Stamp) คือเวลาที่แต่ละเฟรมจะถูกแสดง สมมติเฟรมหนึ่งแสดงที่วินาทีที่ 10 พอคูณด้วย 1.4286 มันจะไปแสดงที่วินาทีที่ 14.286 แทน เฟรมทุกเฟรมถูกเลื่อนห่างออกไป วิดีโอเลยยาวขึ้นและเล่นช้าลง

ตัวเลข 1.4286 มาจาก 100 ÷ 70 ถ้าคูณเวลาด้วยค่ามากกว่า 1 จะช้าลง ถ้าน้อยกว่า 1 จะเร็วขึ้น

**สายเสียง:** `[0:a]atempo=0.7[a]`

| ส่วน | ความหมาย |
|---|---|
| `[0:a]` | เลือกสตรีมเสียง (audio) จากไฟล์ input ลำดับที่ 0 |
| `atempo=0.7` | ปรับความเร็วเสียงเป็น 0.7 เท่า |
| `[a]` | ตั้งชื่อผลลัพธ์ว่า `a` |

`atempo` ปรับความเร็วเสียงโดยพยายามรักษาระดับเสียงสูงต่ำ (pitch) ไว้ ไม่ให้เสียงทุ้มเหมือนเปิดเทปช้า

ข้อสำคัญคือค่า 0.7 ต้องสัมพันธ์กับสายภาพ เพราะ 1 ÷ 1.4286 ≈ 0.7 ถ้าตัวเลขสองฝั่งไม่ตรงกัน ภาพกับเสียงจะเลื่อนไม่ตรงกัน

### 4. `-map "[v]" -map "[a]"`
ปกติ ffmpeg จะเลือกสตรีมให้เอง แต่พอเราใช้ `-filter_complex` ต้องบอกชัด ๆ ว่าจะเอาผลลัพธ์ตัวไหนไปใส่ในไฟล์ปลายทาง

- `-map "[v]"` เอาสายภาพที่ผ่านฟิลเตอร์แล้ว (ชื่อ v)
- `-map "[a]"` เอาสายเสียงที่ผ่านฟิลเตอร์แล้ว (ชื่อ a)

ถ้าไม่ใส่ `-map` ffmpeg จะไม่รู้ว่าต้องใช้ผลลัพธ์จากฟิลเตอร์ และอาจเกิด error หรือได้ไฟล์ที่ไม่ผ่านการปรับความเร็ว

### 5. `output.mp4`
ชื่อไฟล์ที่จะบันทึก ffmpeg ดูจากนามสกุลว่าจะใช้รูปแบบไฟล์อะไร ชื่อต้องไม่ซ้ำกับ input ไม่เช่นนั้นจะเขียนทับต้นฉบับไม่ได้

## ลำดับการทำงานจริง

1. ffmpeg เปิดไฟล์ `input.mp4` แล้วแยกสตรีมภาพกับเสียงออกจากกัน
2. สายภาพผ่าน `setpts` เวลาของทุกเฟรมถูกคูณด้วย 1.4286
3. สายเสียงผ่าน `atempo` เสียงถูกยืดให้ยาวขึ้นเป็น 1 ÷ 0.7 เท่า
4. `-map` เลือกสองสายที่ผ่านฟิลเตอร์แล้ว
5. ffmpeg encode ใหม่ทั้งภาพและเสียง แล้วรวมเป็น `output.mp4`

## ตัวอย่างผลลัพธ์

วิดีโอต้นฉบับยาว 1 นาที (60 วินาที) พอปรับเป็น 70% แล้วจะยาว 60 ÷ 0.7 ≈ **85.7 วินาที** (ประมาณ 1 นาที 26 วินาที)

## ข้อควรระวัง

- ถ้าวิดีโอไม่มีเสียง `[0:a]` จะ error ให้ใช้แบบ `-vf "setpts=1.4286*PTS" -an` แทน
- ต้อง encode ใหม่ จึงใช้เวลาและคุณภาพอาจลดลงเล็กน้อย ถ้าอยากคุมคุณภาพให้เพิ่ม `-crf 18` ต่อท้ายก่อน `output.mp4`
- ถ้าอยากให้ภาพนุ่มลื่นขึ้นตอนช้า สามารถเพิ่ม `minterpolate` ได้ตามที่เคยแนะนำไว้ก่อนหน้านี้
