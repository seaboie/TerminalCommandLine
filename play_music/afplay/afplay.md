
### 📀 Play music in Terminal

```bash
afplay /Users/krit/Music/Music/test/music.mp3
```

### 📀 📀 📀 Loop เล่นเพลงทั้งหมดใน Folder ที่ระบุ
```bash
find /Users/krit/Music/Music/test -name "*.mp3" -exec afplay {} \;
```
#### อธิบายคำสั่ง `find /Users/krit/Music/Music/test -name "*.mp3" -exec afplay {} \;`

คำสั่งนี้เป็นคำสั่ง Unix/Linux/macOS ที่ใช้สำหรับ **ค้นหาไฟล์ MP3 ทั้งหมดในโฟลเดอร์ที่กำหนด แล้วเล่นไฟล์เหล่านั้นทีละไฟล์** มาดูรายละเอียดแต่ละส่วนกันครับ

---

## 🔍 แยกส่วนประกอบของคำสั่ง

### 1. `find`
เป็นคำสั่งพื้นฐานในระบบ Unix ที่ใช้ **ค้นหาไฟล์และโฟลเดอร์** ตามเงื่อนไขที่กำหนด

### 2. `/Users/krit/Music/Music/test`
คือ **path ของโฟลเดอร์เริ่มต้น** ที่จะให้ `find` เริ่มค้นหา
- ในที่นี้คือโฟลเดอร์ `test` ที่อยู่ใน `/Users/krit/Music/Music/`
- `find` จะค้นหาแบบ **recursive** คือไล่ลงไปในโฟลเดอร์ย่อยทั้งหมดด้วย

### 3. `-name "*.mp3"`
เป็น **เงื่อนไขการค้นหา** ระบุว่าให้หาไฟล์ที่มีชื่อลงท้ายด้วย `.mp3`
- `*` คือ wildcard หมายถึง "อะไรก็ได้"
- `"*.mp3"` จึงหมายถึง ไฟล์ทุกชื่อที่เป็นนามสกุล `.mp3`
- ควรใส่เครื่องหมายคำพูด (`"..."`) เพื่อป้องกัน shell ตีความ `*` ก่อนส่งให้ `find`

### 4. `-exec afplay {} \;`
เป็น **action** ที่ให้ `find` ทำกับไฟล์ที่เจอแต่ละไฟล์
- `-exec` = สั่งให้รันคำสั่งกับไฟล์ที่เจอ
- `afplay` = คำสั่งของ macOS ที่ใช้ **เล่นไฟล์เสียง** (Audio File Play)
- `{}` = **placeholder** แทนชื่อไฟล์ที่ `find` เจอในแต่ละรอบ
- `\;` = จุดสิ้นสุดของคำสั่ง `-exec` (ต้อง escape ด้วย backslash `\` เพื่อไม่ให้ shell ตีความ `;` เป็นตัวจบคำสั่ง)

## ⚙️ การทำงานทีละขั้นตอน

สมมติโฟลเดอร์ `/Users/krit/Music/Music/test` มีไฟล์:
```
test/
├── song1.mp3
├── song2.mp3
├── document.pdf
└── subfolder/
    └── song3.mp3
```

เมื่อรันคำสั่ง ระบบจะทำตามลำดับนี้:

1. `find` เริ่มสแกนที่ `/Users/krit/Music/Music/test`
2. เจอ `song1.mp3` → รัน `afplay song1.mp3` → **เล่นเพลงที่ 1 จนจบ**
3. เจอ `song2.mp3` → รัน `afplay song2.mp3` → **เล่นเพลงที่ 2 จนจบ**
4. เจอ `document.pdf` → **ข้ามไป** (ไม่ตรงเงื่อนไข `*.mp3`)
5. เข้าไปใน `subfolder/` → เจอ `song3.mp3` → รัน `afplay song3.mp3` → **เล่นเพลงที่ 3 จนจบ**
6. ค้นหาจบ → จบการทำงาน

> **หมายเหตุสำคัญ:** คำสั่งนี้จะ **เล่นทีละไฟล์แบบเรียงลำดับ (sequential)** เพราะ `afplay` จะบล็อกการทำงานจนกว่าเพลงจะจบ กว่าที่ `find` จะไปเรียกไฟล์ถัดไปได้ ต้องรอเพลงปัจจุบันเล่นจบก่อน

## 🎵 เกี่ยวกับ `afplay`

`afplay` เป็นคำสั่ง built-in ของ macOS ที่ใช้เล่นไฟล์เสียงจาก command line

**รูปแบบการใช้งาน:**
```bash
afplay [options] ไฟล์เสียง
```

**ตัวอย่างการใช้งานอื่น ๆ:**
```bash
afplay song.mp3                    # เล่นเพลง
afplay -v 0.5 song.mp3             # เล่นที่ volume 50%
afplay -t 10 song.mp3              # เล่นแค่ 10 วินาทีแรก
afplay -r 2 song.mp3               # เล่นความเร็ว 2 เท่า
```

---

## ⚠️ ข้อควรระวัง

1. **ต้องเป็น macOS เท่านั้น** — `afplay` ไม่มีใน Linux หรือ Windows
2. **จะเล่นทุกไฟล์จนจบ** — ถ้ามี 100 เพลง ต้องรอเล่นจนครบ 100 เพลง (จะหยุดด้วย Ctrl+C ก็ได้)
3. **ลำดับการเล่นไม่แน่นอน** — `find` ไม่ได้รับประกันลำดับการเรียงไฟล์
4. **ไฟล์ที่มีเว้นวรรคในชื่อ** — คำสั่งนี้ยังทำงานได้ปกติ เพราะ `{}` ถูก quote โดย find อยู่แล้ว

## 💡 ทางเลือกอื่นที่น่าสนใจ

### 📀 📀 📀 ถ้าต้องการเล่นแบบสลับ (shuffle)
```bash
find /Users/krit/Music/Music/test -name "*.mp3" | sort -R | while read f; do afplay "$f"; done
```

### ถ้าต้องการเล่นเฉพาะโฟลเดอร์ปัจจุบัน (ไม่ลง subfolder)
```bash
find /Users/krit/Music/Music/test -maxdepth 1 -name "*.mp3" -exec afplay {} \;
```
